## Project Description
This project is a Python-based Tic-Tac-Toe game
where a human player competes against a computer.

The computer uses rule-based artificial intelligence
to make intelligent decisions.

## Features
- Human vs Computer gameplay
- Rule-based AI opponent
- Immediate winning move detection
- Blocking opponent's winning move
- Center and corner preference
- Win, loss, and draw detection
- Input validation
- Replay functionality

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python tic_tac_toe.py

## AI Logic
The computer follows these rules:

1. Win if possible.
2. Block the human's winning move.
3. Choose the center.
4. Choose an available corner.
5. Choose any remaining position.
